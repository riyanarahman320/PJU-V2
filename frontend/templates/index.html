ASEP-JAGA

Sistem emergency pada infrastruktur Penerangan Jalan Umum (PJU) berbasis ESP32-S3 dengan verifikasi dua tahap: verifikasi lokal di perangkat dan verifikasi kedua di server.

Buka Command Center Cek Status API

Alur Sistem

USER | v SOS BUTTON + MICROPHONE | v ESP32-S3 -> LOCAL AUDIO AI -> LOCAL VERIFICATION | +-- TIDAK VALID --> STOP | +-- VALID --------> STROBE ON (langsung, tanpa server) | v KIRIM DATA KE SERVER | v CONTEXT PROCESSING | v VERIFIKASI TAHAP 2 | +-------------+-------------+ | | FALSE ALARM CONFIRMED | | STOP COMMAND | v ESP32 | v SIREN + SPEAKER

Status Implementasi

Bagian yang sudah berfungsi pada tahap ini:

  • REST API Flask + database SQLite
  • Registrasi perangkat dan heartbeat
  • Verifikasi tahap 2 (rule-based, bukan AI)
  • Pengelolaan incident dan command
  • Dashboard, peta, dan riwayat
  • Simulator perangkat
Catatan jujur. Verifikasi tahap 2 saat ini memakai aturan berbobot tetap yang ditulis manual, belum model AI. Data hotspot, cuaca, dan lalu lintas masih mock yang dihasilkan secara lokal. Modul AI Python akan diintegrasikan pada tahap berikutnya melalui register_ai_verifier().
